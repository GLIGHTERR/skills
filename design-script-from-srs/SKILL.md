# Figma SRS Designer

Sinh Figma Plugin Script từ tài liệu SRS và ảnh mockup. Script được chạy trực tiếp
trong Figma Desktop App thông qua plugin cộng đồng — không cần build plugin riêng.

---

## Yêu cầu hệ thống

| Thành phần | Chi tiết |
|---|---|
| **Figma Desktop App** | Bắt buộc (plugin script không chạy trên web) |
| **Plugin trong Figma** | [Run Plugin API](https://www.figma.com/community/plugin/1061937426144722953) hoặc [FigmaScript](https://www.figma.com/community/plugin/1185220808664451993/figmascript) |
| **Gemini CLI** | `gemini` với model có hỗ trợ Vision (để đọc mockup ảnh) |
| **Input** | File SRS (`.md`, `.txt`, `.pdf`, `.docx`) + ảnh mockup (tuỳ chọn) |

---

## Cách sử dụng (dành cho người dùng)

### Bước 1 — Cài plugin vào Figma

1. Mở **Figma Desktop App**
2. Vào trang: https://www.figma.com/community/plugin/1061937426144722953/run-plugin-api
3. Nhấn **"Open in Figma"** → **"Install"**

### Bước 2 — Chạy Gemini CLI

```bash
# Chỉ có SRS
gemini -f srs.md "Tạo Figma script cho tất cả màn hình trong SRS này"

# SRS + mockup ảnh
gemini -f srs.md -f mockup-login.png -f mockup-dashboard.png \
  "Tạo Figma script dựa trên SRS và lấy cảm hứng layout/màu sắc từ các mockup này"
```

### Bước 3 — Chạy script trong Figma

1. Mở Figma Desktop → mở file bất kỳ
2. Menu: **Plugins → Run Plugin API**
3. Xoá code mẫu → Paste toàn bộ script được sinh
4. Nhấn **Run** (▶) → Design tự động xuất hiện trên canvas

## Quy trình xử lý của Gemini

### Giai đoạn 1: Phân tích SRS

Trích xuất từ tài liệu SRS:

```
- Danh sách màn hình / pages
- Các thành phần UI trên mỗi màn hình (header, nav, form, table, card, button...)
- User flows và trạng thái (loading, empty, error)
- Typography hints (tiêu đề, body text)
- Color hints (brand color, trạng thái lỗi/thành công)
```

### Giai đoạn 2: Phân tích mockup (nếu có ảnh)

Dùng Gemini Vision để trích xuất:

```
- Layout structure (grid, stack, sidebar...)
- Spacing ước lượng (8px grid system)
- Color palette chính (hex → convert sang r/g/b 0-1)
- Typography scale (font size tương đối)
- Component patterns đặc trưng
```

### Giai đoạn 3: Sinh Figma Plugin Script

Output là một file `.js` hợp lệ chạy trong Figma Plugin API.

## Chuẩn sinh code

### Cấu trúc script bắt buộc

```javascript
// ============================================================
// FIGMA DESIGN SCRIPT — Generated by Gemini CLI
// SRS: [tên file SRS]
// Screens: [số lượng màn hình]
// Generated: [ngày]
// ============================================================
// HOW TO RUN:
// 1. Open Figma Desktop App
// 2. Plugins → Run Plugin API (or FigmaScript)
// 3. Paste this entire script → click Run (▶)
// ============================================================

(async () => {

  // --- DESIGN TOKENS ---
  const TOKENS = {
    colors: {
      primary:     { r: 0.20, g: 0.47, b: 1.00 },
      secondary:   { r: 0.58, g: 0.33, b: 1.00 },
      background:  { r: 0.97, g: 0.97, b: 0.99 },
      surface:     { r: 1.00, g: 1.00, b: 1.00 },
      error:       { r: 0.93, g: 0.26, b: 0.26 },
      success:     { r: 0.20, g: 0.78, b: 0.35 },
      textPrimary: { r: 0.10, g: 0.10, b: 0.10 },
      textSecond:  { r: 0.45, g: 0.45, b: 0.52 },
      border:      { r: 0.87, g: 0.87, b: 0.90 },
    },
    spacing: { xs: 4, sm: 8, md: 16, lg: 24, xl: 32, xxl: 48 },
    radius:  { sm: 4, md: 8, lg: 12, xl: 16, full: 999 },
    font: {
      h1: 32, h2: 24, h3: 18, h4: 16,
      body: 14, small: 12, caption: 10,
    },
  };

  // --- FONT LOADING (load trước khi dùng createText) ---
  await figma.loadFontAsync({ family: 'Inter', style: 'Regular' });
  await figma.loadFontAsync({ family: 'Inter', style: 'Medium' });
  await figma.loadFontAsync({ family: 'Inter', style: 'Bold' });
  await figma.loadFontAsync({ family: 'Inter', style: 'SemiBold' });

  // --- HELPER FUNCTIONS ---
  // [các hàm helper — xem phần bên dưới]

  // --- SCREENS ---
  // [mỗi màn hình được sinh thành 1 function]

  // --- MAIN EXECUTION ---
  const allScreens = [];
  let xOffset = 0;

  const screens = [
    buildScreen_Login,
    buildScreen_Dashboard,
    // ... thêm screens tương ứng SRS
  ];

  for (const buildFn of screens) {
    const frame = await buildFn(xOffset);
    allScreens.push(frame);
    xOffset += frame.width + TOKENS.spacing.xxl * 2;
  }

  figma.currentPage.selection = allScreens;
  figma.viewport.scrollAndZoomIntoView(allScreens);
  figma.closePlugin(`✅ Đã tạo ${allScreens.length} màn hình thành công!`);

})();
```

### Helper functions chuẩn

Luôn bao gồm các helper sau trong mỗi script sinh ra:

```javascript
// Tạo text node
async function makeText(content, size, colorKey, fontStyle = 'Regular') {
  const t = figma.createText();
  t.fontName = { family: 'Inter', style: fontStyle };
  t.characters = content;
  t.fontSize = size;
  t.fills = [{ type: 'SOLID', color: TOKENS.colors[colorKey] || TOKENS.colors.textPrimary }];
  return t;
}

// Tạo rectangle (nền, divider, avatar placeholder...)
function makeRect(w, h, colorKey, radius = 0) {
  const r = figma.createRectangle();
  r.resize(w, h);
  r.cornerRadius = radius;
  r.fills = [{ type: 'SOLID', color: TOKENS.colors[colorKey] || { r: 0.9, g: 0.9, b: 0.9 } }];
  return r;
}

// Tạo auto-layout frame (container chuẩn)
function makeAutoFrame(name, direction, spacing, padding) {
  const f = figma.createFrame();
  f.name = name;
  f.layoutMode = direction; // 'VERTICAL' hoặc 'HORIZONTAL'
  f.primaryAxisSizingMode = 'AUTO';
  f.counterAxisSizingMode = 'AUTO';
  f.itemSpacing = spacing;
  if (typeof padding === 'number') {
    f.paddingTop = f.paddingBottom = f.paddingLeft = f.paddingRight = padding;
  } else {
    f.paddingTop    = padding.top    ?? 0;
    f.paddingBottom = padding.bottom ?? 0;
    f.paddingLeft   = padding.left   ?? 0;
    f.paddingRight  = padding.right  ?? 0;
  }
  f.fills = [];
  return f;
}

// Tạo button
async function makeButton(label, style = 'primary', width = 0) {
  const btn = figma.createFrame();
  btn.name = `Button/${label}`;
  btn.layoutMode = 'HORIZONTAL';
  btn.primaryAxisAlignItems = 'CENTER';
  btn.counterAxisAlignItems = 'CENTER';
  btn.paddingTop = btn.paddingBottom = 10;
  btn.paddingLeft = btn.paddingRight = 20;
  btn.cornerRadius = TOKENS.radius.md;
  btn.primaryAxisSizingMode = width > 0 ? 'FIXED' : 'AUTO';
  if (width > 0) btn.resize(width, btn.height);

  const isOutline = style === 'outline';
  btn.fills = isOutline
    ? [{ type: 'SOLID', color: TOKENS.colors.surface }]
    : [{ type: 'SOLID', color: TOKENS.colors.primary }];

  if (isOutline) {
    btn.strokes = [{ type: 'SOLID', color: TOKENS.colors.primary }];
    btn.strokeWeight = 1;
  }

  const labelText = await makeText(
    label,
    TOKENS.font.body,
    isOutline ? 'primary' : 'surface',
    'Medium'
  );
  if (!isOutline) labelText.fills = [{ type: 'SOLID', color: { r: 1, g: 1, b: 1 } }];
  btn.appendChild(labelText);
  return btn;
}

// Tạo input field
async function makeInput(placeholder, width = 280) {
  const input = figma.createFrame();
  input.name = `Input/${placeholder}`;
  input.layoutMode = 'HORIZONTAL';
  input.counterAxisAlignItems = 'CENTER';
  input.resize(width, 44);
  input.cornerRadius = TOKENS.radius.md;
  input.fills = [{ type: 'SOLID', color: TOKENS.colors.surface }];
  input.strokes = [{ type: 'SOLID', color: TOKENS.colors.border }];
  input.strokeWeight = 1;
  input.paddingLeft = input.paddingRight = TOKENS.spacing.md;

  const ph = await makeText(placeholder, TOKENS.font.body, 'textSecond');
  input.appendChild(ph);
  return input;
}

// Tạo card container
function makeCard(name, width, radius = TOKENS.radius.lg) {
  const card = figma.createFrame();
  card.name = name;
  card.layoutMode = 'VERTICAL';
  card.primaryAxisSizingMode = 'AUTO';
  card.counterAxisSizingMode = 'FIXED';
  card.resize(width, 100);
  card.cornerRadius = radius;
  card.fills = [{ type: 'SOLID', color: TOKENS.colors.surface }];
  card.effects = [{
    type: 'DROP_SHADOW',
    color: { r: 0, g: 0, b: 0, a: 0.08 },
    offset: { x: 0, y: 2 },
    radius: 8,
    spread: 0,
    visible: true,
    blendMode: 'NORMAL',
  }];
  return card;
}
```

## Cấu trúc mỗi màn hình

Mỗi screen SRS được sinh thành 1 async function:

```javascript
async function buildScreen_Login(xOffset = 0) {
  // 1. Tạo màn hình ngoài cùng (Phone/Web frame)
  const screen = figma.createFrame();
  screen.name = '📱 Login Screen';
  screen.resize(390, 844);  // iPhone 14 Pro
  screen.x = xOffset;
  screen.y = 0;
  screen.fills = [{ type: 'SOLID', color: TOKENS.colors.background }];
  screen.clipsContent = true;
  figma.currentPage.appendChild(screen);

  // 2. Đặt layout mode cho screen
  screen.layoutMode = 'NONE'; // Dùng absolute positioning

  // 3. Thêm các phần tử
  // Header
  const header = await makeText('Đăng nhập', TOKENS.font.h2, 'textPrimary', 'Bold');
  header.x = TOKENS.spacing.xl;
  header.y = 100;
  screen.appendChild(header);

  // Form
  const emailInput = await makeInput('Email của bạn');
  emailInput.x = TOKENS.spacing.xl;
  emailInput.y = 160;
  screen.appendChild(emailInput);

  const passwordInput = await makeInput('Mật khẩu');
  passwordInput.x = TOKENS.spacing.xl;
  passwordInput.y = 220;
  screen.appendChild(passwordInput);

  // Button
  const loginBtn = await makeButton('Đăng nhập', 'primary', 310);
  loginBtn.x = TOKENS.spacing.xl;
  loginBtn.y = 300;
  screen.appendChild(loginBtn);

  return screen;
}
```

## Xử lý màu từ mockup

Khi Gemini Vision phân tích mockup, convert màu sang format Figma:

```
HEX #3366FF → r: 0.20, g: 0.40, b: 1.00
HEX #FFFFFF → r: 1.00, g: 1.00, b: 1.00
HEX #1A1A2E → r: 0.10, g: 0.10, b: 0.18

Công thức: component / 255 (làm tròn 2 chữ số thập phân)
```

Ưu tiên màu từ mockup. Nếu không có mockup → dùng bảng màu mặc định trong TOKENS.

## Các thành phần UI phổ biến

Khi SRS đề cập đến các thành phần sau, sinh code tương ứng:

| SRS đề cập | Component sinh ra |
|---|---|
| Navigation bar / bottom nav | Frame horizontal + icon placeholder + text |
| App header / top bar | Frame 390×56 + title text + back icon rect |
| Form đăng nhập / đăng ký | makeInput × n + makeButton |
| Danh sách / list items | Vòng lặp tạo card với avatar + text |
| Bảng dữ liệu (table) | Grid frame với header row + data rows |
| Modal / dialog | Frame chồng lên với semi-transparent overlay |
| Tab bar | Frame horizontal với tab items |
| Search bar | makeInput với icon search placeholder |
| Card grid | Vòng lặp tạo card 2 cột |
| Empty state | Icon placeholder + heading + subtext + button |
| Loading state | Skeleton rectangles với fill màu nhạt |

## Lưu ý quan trọng khi sinh code

1. **Luôn `await figma.loadFontAsync()`** trước khi gọi `figma.createText()` hoặc thay đổi `fontName`
2. **Không set `maxHeight` trước `layoutMode`** — phải set `layoutMode` trước
3. **`figma.closePlugin(message)`** phải là dòng cuối cùng trong async IIFE
4. **Không dùng `fetch()` trực tiếp** từ main thread — chỉ dùng được trong iframe
5. **Màu sắc luôn ở dạng `{ r, g, b }`** với giá trị 0–1, không phải 0–255
6. **Append vào `figma.currentPage`** trước khi set position tuyệt đối
7. **Khi dùng absolute position** (`layoutMode = 'NONE'`): set `x`, `y` sau khi `appendChild`

## Template kiểm tra nhanh (Hello World)

Script tối giản để test plugin đang hoạt động:

```javascript
(async () => {
  await figma.loadFontAsync({ family: 'Inter', style: 'Bold' });

  const frame = figma.createFrame();
  frame.name = 'Test Frame';
  frame.resize(390, 200);
  frame.fills = [{ type: 'SOLID', color: { r: 0.20, g: 0.47, b: 1.00 } }];
  figma.currentPage.appendChild(frame);

  const text = figma.createText();
  text.fontName = { family: 'Inter', style: 'Bold' };
  text.characters = '✅ Plugin hoạt động tốt!';
  text.fontSize = 24;
  text.fills = [{ type: 'SOLID', color: { r: 1, g: 1, b: 1 } }];
  text.x = 40;
  text.y = 80;
  frame.appendChild(text);

  figma.viewport.scrollAndZoomIntoView([frame]);
  figma.closePlugin('Done!');
})();
```

## Xử lý lỗi thường gặp

| Lỗi | Nguyên nhân | Giải pháp |
|---|---|---|
| `Font not loaded` | Dùng `createText` trước `loadFontAsync` | Luôn load font ở đầu script |
| `Cannot set property of read-only` | Append vào node chưa add vào page | `currentPage.appendChild()` trước |
| `Plugin closed` ngay lập tức | `closePlugin()` không nằm trong async | Bọc toàn bộ trong `(async () => { ... })()` |
| Script chạy nhưng không có gì | Script chạy xong trước khi await | Kiểm tra tất cả các hàm async đều được `await` |
| Màu sai / trắng xóa | Giá trị màu > 1 | Chia 255: `{ r: 51/255, g: 102/255, b: 255/255 }` |
